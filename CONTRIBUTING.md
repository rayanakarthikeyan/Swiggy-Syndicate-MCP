# Contributing to Swiggy Syndicate

Thank you for your interest in contributing to Swiggy Syndicate MCP.

1# Development Workflow

1. Fork and clone the repository.
2. Install dependencies: `npm install`
3. Build the project: `npm run build`
4. Run the test suite: `npm test`
5. Test the interactive runner: `npm run demo`

## Guidelines

- Ensure any new tool adhering to Swiggy MCP matches official schemas at https://mcp.swiggy.com/builders/.
- Write unit tests for all constraint optimization modifications.
- Maintain strict typing with TypeScript.
